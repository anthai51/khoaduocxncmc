# Website Khoa Dược - Xét nghiệm

Địa chỉ: https://khoaduocxncmc.id.vn

## Tự chỉnh sửa nội dung ngay trên website

1. Mở trang cần sửa, kéo xuống cuối trang, bấm **✏️ Chỉnh sửa trang**.
2. Lần đầu: dán **mã truy cập GitHub** (hướng dẫn tạo mã có sẵn trong hộp đăng nhập).
3. Bấm vào chữ để sửa; dùng thanh công cụ ở dưới để in đậm, nghiêng, tạo danh sách, chèn liên kết, chèn ảnh.
4. Bấm vào ảnh bất kỳ để thay ảnh khác.
5. Trang **Kiến thức đời sống**: nút **＋ Bài viết** để tạo bài mới; nút **×** trên thẻ để gỡ bài khỏi danh sách.
6. Bấm **💾 Lưu**. Trang công khai cập nhật sau khoảng 1 phút (nhấn Ctrl + F5 nếu chưa thấy).

Trên máy đã đăng nhập sẽ có nút **✏️ Sửa trang** ở góc trái dưới. Bấm **Đăng xuất** để xóa mã truy cập khỏi máy dùng chung.

## Sửa menu

Menu và chân trang dùng chung nằm trong `assets/js/layout.js` (mảng `MENU`).
